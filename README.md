# 有理采样率的分块 FIR 重采样库

实数单通道有理采样率（L/M）FIR 重采样，支持输入分块到达，结果与整段一次性处理严格一致。完整规格见 TASK.md。

## 数学定义

`u[nL]=x[n]`（其余为 0），`z[t]=sum(j=0..K-1, h[j]*u[t-j])`，`y[q]=z[qM]`。
累计输入 N>0 时完整输出为所有满足 `0<=qM<=(N-1)L+K-1` 的 `y[q]`；N=0 输出空序列，域外输入为 0。

## 接口（包 `resampler`，仅标准库）

- `New(L, M int, h []float64) (*Resampler, error)` — 要求 `1<=L,M<=64` 且互质，`1<=len(h)<=257`，系数有限且 `|h|<=16`。
- `Feed(block []float64) ([]float64, error)` — 送入一个块，返回新产生的输出（`qM<=min(NL-1,(N-1)L+K-1)` 且尚未输出的部分）。样本须有限且 `|x|<=1`；非法块整体拒绝、状态不变。计数将溢出 int64 时同样整体拒绝。
- `Finish() ([]float64, error)` — 按完整定义补齐尾部；重复调用返回空成功；之后 `Feed` 返回 `ErrFinished`。
- `Reset()` — 恢复初始状态。
- `TotalInput() / TotalOutput() int64`、`Buffered() int`、`BufferedBound() int` — 累计输入/输出计数与历史缓冲样本数；缓冲上界为 `(K-1)/L+1`，只与 K、L 相关。

实现使用多相系数与有限历史，不构造 L 倍上采样数组，也不保存全部输入历史。

## 运行

Windows 原生 Go 1.26.5，仅标准库，无第三方依赖、无外部服务。

```sh
go run ./cmd/demo                        # 演示：分块一致、Finish 尾部、一次实际触发的非法块拒绝
go test ./... -count=1 -timeout=60s      # 测试
```

测试覆盖：K<L 输出域、空块/空输入、L=M=1、升/降采样、冲激、Finish 尾部、坏块原子拒绝、Reset、计数与缓冲上界、构造参数校验、int64 溢出前拒绝，以及固定种子随机参数下单切点/多分块与直接上采样卷积参考的一致性（误差 `<=1e-10*(1+|ref|)`，含 L=4,M=1,K=1,N=1 只输出一个样本的用例）。
